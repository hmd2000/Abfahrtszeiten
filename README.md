# Abfahrtszeiten

Web-App, die mit Verkehrsdaten von TomTom die beste Abfahrtszeit für den Arbeitsweg (morgens und Feierabend) ermittelt.

- Läuft komplett im Browser, eine Datei: `index.html`
- Datenquelle: TomTom Routing API (20.000 Abfragen/Monat kostenlos, ohne Kreditkarte). Google Routes optional.
- Der API-Schlüssel wird nur im Browser gespeichert und steht nicht im Code.
